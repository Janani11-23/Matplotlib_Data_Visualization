# Matplotlib_Data_Visualization
# 📊 Monthly Sales Analysis Dashboard Using Python Matplotlib

## 📌 Project Overview

This project focuses on visualizing monthly sales data and product prices using **Python Matplotlib**. I created a dashboard-style visualization containing three different charts to understand sales trends, compare product prices, and analyze monthly sales distribution.

The project was developed using **Google Colab** as part of my hands-on learning in Python data visualization.

## 🎯 Objectives

- Analyze monthly sales trends from January to July.
- Compare prices across different products.
- Visualize each month's contribution to total sales.
- Learn to customize charts using Matplotlib.
- Present numerical data through clear and meaningful visualizations.

## 📈 Visualizations Created

### 1. Monthly Sales Trend — Line Chart

- Visualizes monthly sales from January to July.
- Highlights changes in sales over time.
- Uses customized line styles, markers, colors, and line width.
- Applies `fill_between()` to highlight the area under the sales line.
- Includes gridlines and a legend for better readability.

### 2. Price per Product — Bar Chart

- Compares the prices of seven products: Laptop, PS5, Mobile, Shoes, Bike, Boat, and Aeroplan.
- Uses different colors to distinguish products.
- Customizes bar borders, gridlines, and x-axis label rotation.
- Helps identify the highest- and lowest-priced products.

### 3. Monthly Sales Percentage — Pie Chart

- Displays the percentage contribution of each month to total sales.
- Uses `autopct` to display percentage values.
- Applies different colors using the Matplotlib colormap.
- Uses exploded slices and a shadow effect to improve presentation.

## 💡 Key Insights

- **Highest monthly sales:** May — 40,000.
- **Lowest monthly sales:** January — 25,000.
- **Highest-priced product:** Bike — 200,000.
- **Lowest-priced product:** Mobile — 20,000.
- The pie chart shows how each month contributes to the total sales recorded during the seven-month period.

## 📚 Python Concepts Practiced

- Creating line, bar, and pie charts.
